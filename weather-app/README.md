# Weather App

A responsive weather application built with React and TypeScript that allows users to browse predefined cities and view detailed weather information.

## Tech Stack

- React
- TypeScript
- Vite
- React Router
- TanStack Query
- Vitest
- React Testing Library
- WeatherAPI

## Features

- List of predefined cities
- Weather details page
- Current weather conditions
- Temperature periods (Dawn, Morning, Afternoon, Night)
- Responsive design for mobile, tablet, and desktop
- Unit tests

## Installation

```bash
npm install
```

## Running the Application

```bash
npm run dev
```

The application will be available at:

```txt
http://localhost:5173
```

## Running Tests

```bash
npm run test
```

## Building for Production

```bash
npm run build
```
